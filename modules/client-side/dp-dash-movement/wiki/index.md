## Quick Orientation

**What is this project?**
A React-based job dashboard built as a Web Component (`<dash-movement>`), embedded inside an Angular client portal application.

**Where to start?**
- Understanding the system → [architecture.md](architecture.md)
- Recent changes → [logs.md](logs.md)
- Known problems → [issues.md](issues.md)

## Wiki Maintenance Rules

- `issues.md` is updated only after a fix is confirmed working by the user
- `logs.md` is updated after every significant change or fix
- `architecture.md` is updated when structural decisions change
- This index is updated when new wiki pages are added
