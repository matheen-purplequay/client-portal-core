# Issues

This file tracks known issues, their status, and resolution notes. It is updated only after a fix has been confirmed working.

## Format

```
### [ISSUE-NNN] Short title
- **Status:** Open | Resolved
- **Reported:** YYYY-MM-DD
- **Resolved:** YYYY-MM-DD (if applicable)
- **Area:** affected module/file
- **Description:** what the problem is
- **Fix:** what was done to resolve it
```
